## Repository Structure

- `queue/` — Projects waiting to be published.
- `src/` — Projects already published.
- `.github/workflows/daily-project.yml` — Daily automation.
- `scripts/update_progress.py` — README progress updater.

## Automation

Every scheduled run finds the lowest-numbered project in `queue/`, moves it into `src/`, marks it complete in this README, commits the change, and pushes it to GitHub.

After the final project is published, the empty `queue/` directory is removed.

## Schedule

The workflow runs daily at **09:00 IST (03:30 UTC)** and can also be started manually from GitHub Actions.

## Security

Never commit passwords, API tokens, private keys, cloud credentials, `.env` files, or other secrets.
